The jetls executable

The jetls executable is the main entry point for JETLS, providing the following commands:

  • jetls serve - Start the language server for editor integration
  • jetls check - Run diagnostics from the command line
  • jetls test - Run tests with TestRunner.jl from the command line
  • jetls schema - Print JSON Schema for JETLS configuration
  • jetls version - Show version information

The executable is installed as an executable app via Pkg.jl. See Installing the jetls executable for the installation and update instructions.

Command reference

jetls --help

JETLS - A Julia language server with runtime-aware static analysis,
powered by JET.jl, JuliaSyntax.jl, and JuliaLowering.jl

VERSION: dev

Usage: jetls <COMMAND> [OPTIONS]

Commands:
  serve                       Start language server
  check [<path>...]           Run diagnostics on Julia files
  test <path> [<pattern>...]  Run tests with TestRunner.jl
  schema                      Print JSON schema for configuration
  version                     Show version information

Common options:
  --version, -v               Show version information
  --help, -h                  Show this help message

Run 'jetls <command> --help' for command-specific options.

Examples:
  jetls serve --pipe-listen=/tmp/jetls.sock
  jetls check src/SomePkg.jl
  jetls test test/runtests.jl "selected tests"
  jetls schema --settings

Julia runtime flags

Since jetls is an executable Julia app, you can pass Julia runtime flags before -- to configure the Julia runtime. This is especially useful for controlling threading behavior. JETLS's signature analysis phase is parallelized, so increasing thread count may improve analysis performance.

# Run with 4 default threads and 2 interactive threads
jetls --threads=4,2 -- check src/SomePkg.jl

For more details on available runtime flags, see the Pkg documentation on runtime flags.
